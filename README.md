# 💼 Sistema de Gestión de Nóminas (NomiSpan)

Un sistema eficiente, moderno y extensible para la gestión integral de nóminas de empleados, desarrollado utilizando las últimas novedades de **Java 25**.

---

## 🎯 Acerca del Proyecto

El **Sistema de Gestión de Nóminas** permite automatizar y simplificar la administración de pagos, cálculo de deducciones (impuestos, seguridad social), horas extra, bonificaciones y generación de recibos de nómina para distintas categorías de empleados en una organización.

Diseñado con un enfoque modular y limpio, aprovecha el rendimiento y las nuevas capacidades del lenguaje Java 25 para ofrecer un procesamiento rápido y robusto de datos financieros.

---

## ✨ Características Principales

- 👤 **Gestión de Empleados:** Alta, baja y actualización de información personal y contractual (empleados a tiempo completo, parcial, por contrato o ejecutivos).
- 🧮 **Cálculo Automático de Nómina:**
  - Cálculo de salario bruto y neto.
  - Deducciones configurables (impuestos, retenciones, beneficios).
  - Gestión de horas extra y bonificaciones especiales.
- 📄 **Generación de Reportes e Históricos:** Creación de recibos de nómina detallados y exportación a formatos estándar (PDF/CSV/JSON).
- ⚡ **Procesamiento Concurrente:** Procesamiento de múltiples nóminas en paralelo aprovechando hilos virtuales (*Virtual Threads*).
